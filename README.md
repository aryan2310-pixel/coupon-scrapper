<h1>Zepto Coupon Scraper</h1>

<h3>Directions to use:- </h3>
<ol>
  <li>clone the repository in your pc</li>
  <li>run the python script file </li>
  <li>it will open zepto in browser (chromium)</li>
  <li>login your account on zepto </li>
  <li>navigate yourself to the coupons or payment offers tab</li>
  <li>now wait for 5 seconds</li>
  <li>all the offers will be printed in your terminal</li>
  <li>if you want the response in json, a file named with "zepto_coupons.json"will be there for json data</li>
</ol>

<h3>To see the coupons in cards form</h3>
<li>in your terminal "cd frontend"</li>
<li>npm install</li>
<li> run "npm run dev" </li>
<li>open that localhost link in browser </li>

<h4>Limitations</h4>
<ol>
  <li>you cannot get coupons and payment offers at once in a json file</li>
  <li>if try to run react app directly immediately after cloning the repo will throw an error</li>
</ol>
